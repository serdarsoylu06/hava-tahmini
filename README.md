# HavaLab

Open-Meteo verisiyle çalışan, tek dosyalık Bento hava durumu web uygulaması (`web/hava-bento.html`).

## Yapı

- `web/hava-bento.html` — Sade ve Uzman modlu, canlı gökyüzü arka planlı tek dosyalık hava durumu uygulaması.
- `assets/` — Açık ve koyu tema SVG logoları.
